# Локальна перевірка домашнього завдання Security

Запускай команди з папки `online-book-shop`.

```sh
mvn clean verify
mvn spring-boot:run
```

Для запуску застосунку потрібна MySQL з налаштуваннями з
`src/main/resources/application.properties`. Тести використовують окрему H2
у пам’яті, застосовують міграції Liquibase та перевіряють схему через Hibernate.
Під час першого запуску застосунку Liquibase застосує нові changeset-и до MySQL.
Попередні changeset-и не змінено.

## Автентифікація та ролі

HTTP Basic: ім’я користувача — email, пароль — пароль реєстрації.
Паролі зберігаються як BCrypt-хеші. `/login` не потрібен.

- `POST /api/auth/register` — публічна реєстрація з роллю USER.
- `POST /api/auth/registration` — збережений сумісний шлях реєстрації.
- `GET /api/books`, `/api/books/{id}`, `/api/books/search` — роль USER.
- `POST /api/books`, `PUT /api/books/{id}`, `DELETE /api/books/{id}` — роль ADMIN.
- Swagger: http://localhost:8080/api/swagger-ui/index.html — доступний без входу.
  Кнопка Authorize дозволяє вказати HTTP Basic облікові дані.

Liquibase створює навчального адміністратора:

- Email: `admin@bookstore.local`
- Пароль: `LocalAdmin2026!`
- Ролі: ADMIN і USER, тому він може також читати каталог.

Ці облікові дані призначені для локального навчального проєкту.
Міграція зупиняється, якщо email адміністратора вже зайнятий: наявному
обліковому запису автоматично не надаються адміністративні права.
Усі наявні користувачі отримують USER. Міграція не змінює їхні паролі;
якщо раніше вони зберігалися відкритим текстом, потрібне окреме переведення
на BCrypt або скидання пароля.

Приклад запиту:

```sh
curl -u 'admin@bookstore.local:LocalAdmin2026!' http://localhost:8080/api/books
```

Тести перевіряють реєстрацію та збереження персональних даних, BCrypt,
роль USER за замовчуванням, повторну реєстрацію, відповіді 401/403,
доступ за ролями, операції з книгами, вимкнений обліковий запис і Swagger.
Mockito налаштовано на subclass mock maker у тестових ресурсах.

Сутності Order у поточному проєкті немає. Згадка про замовлення у вступі
завдання не відповідає його детальному переліку сутностей та ендпоінтів;
каталог книг спільний для користувачів.
